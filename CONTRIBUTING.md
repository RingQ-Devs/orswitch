# Contributing to OpenRings

Thank you for helping. Issues, pull requests, documentation fixes and dialplan
examples are all welcome.

## Contributor License Agreement

OpenRings is offered under the AGPL v3 and under a commercial license from
RingQ Ltd. To keep both possible, every contributor signs the
[Contributor License Agreement](CLA.md) once, before their first pull request
is merged. You keep the copyright in your work; you give RingQ Ltd a license
to use it, including in commercially licensed versions.

## Pull requests

1. Open an issue first for anything larger than a small fix.
2. Keep each pull request to one change, with tests (`make test`).
3. Run `make test` and `make race` before you push.
4. Add `SPDX-License-Identifier: AGPL-3.0-only` to the top of new source files.
